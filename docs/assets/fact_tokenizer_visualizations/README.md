# FACT Tokenizer Visualizations

This directory stores selected PNG visualizations copied from local FACT tokenizer experiment runs for GitHub review.

Only lightweight reporting images are committed here. Raw outputs, checkpoints, datasets, and run directories remain ignored.

Included groups:

- `egoexo_debug_dino_*`: smoke/debug training curves and token diagnostics.
- `egoexo_diverse_500takes_k64_20k_ddp4_resumable_20260615_181053`: v0.1 training curves and token diagnostics.
- `v5k_4p0_usage_antitake_repair_8gpu_20260617_211752`: 4.0 non-multi-exo training curves, action diagnostics, and code usage.
- `v5l_transition48_dense_from_v5f_20260618_121935`: transition48 training curves, action diagnostics, and code usage.
